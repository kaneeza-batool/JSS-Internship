Program overview

What this program covers

The Azure Cloud Engineer Certificate Program is designed to equip you with the advanced technical skills needed to excel in cloud computing and infrastructure management using Microsoft Azure. This program covers all essential aspects of Azure administration, from foundational concepts to complex infrastructure management and DevOps practices.

The program consists of two main courses that focus on the core and specialized aspects of Azure. You'll gain hands-on experience through practical labs and real-world case studies, preparing for a career as an Azure specialist or DevOps engineer.

Program outcomes

What you'll be able to do

  • Configure Azure Active Directory and manage users
  • Implement role-based access control
  • Manage subscriptions and governance
  • Deploy and manage virtual machines
  • Create and manage containers
  • Deploy applications using Docker and Kubernetes
  • Implement DevOps practices and use Azure Boards
