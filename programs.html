FAQ

Programs & courses, answered

Common questions about how programs and individual courses work.

What's the difference between a Program and a Course?+

A Program is an ordered sequence of Courses built around one job outcome. A Course is a single focused unit you can take on its own.

Do I need the Free plan before Premium?+

No — you can start on Premium directly. Free is there if you'd rather try the fundamentals courses first.

Are labs included in every program?+

Yes, every certificate program includes hands-on labs. Lab depth varies by plan — see the pricing page for details.
